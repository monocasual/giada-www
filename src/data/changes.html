This release introduces elastic time-stretching for sample channels, letting users independently adjust playback speed and pitch, powered by the Rubber Band audio library. The Sample Editor has been reworked accordingly with a redesigned Pitch/Time panel, a new Playback Mode selector (Tape vs. Elastic), a quick "Adjust..." menu for common pitch/time operations, and a dedicated sample info window.

  • Add elastic (time-stretching) playback mode for sample channels, allowing tempo and pitch to be changed independently;
  • Sample Editor: major UI rework, focusing on the pitch tools and audio file info sections;
  • Sample Editor: organize the sample-spreading actions (spread to bar, spread to song) into a dedicated menu;
  • Sample Editor: add "+1 Semitone" and "-1 Semitone" options to quickly adjust sample pitch in semitone increments;
  • Improve audio buffer performance and internal data handling by switching to a more efficient memory layout;
  • CMake: add a new WITH_ASAN option (disabled by default) to build with AddressSanitizer + UndefinedBehaviorSanitizer;
  • Fix a crash that could occur when closing sub-windows;
  • Various minor internal optimizations and code cleanups.
